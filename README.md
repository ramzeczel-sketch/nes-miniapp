# NES / Dendy Mini App для Telegram

Telegram Mini App: эмулятор NES/Famicom (Dendy) в браузере, библиотека игр, соло-режим и лобби на двоих
(игра по сети, lockstep). Эмулятор — [jsnes](https://github.com/bfirsh/jsnes) (Apache-2.0).

## Что умеет
- Библиотека игр с пометками 1P / 2P.
- Соло — сразу играешь. Тач-геймпад (крестовина, A, B, Start, Select) + клавиатура
  (P1: стрелки, X=A, Z=B, Enter=Start, Shift=Select).
- Лобби: создаёшь → получаешь короткий код и ссылку `https://t.me/<bot>?startapp=<код>` → кидаешь другу
  кнопкой «Позвать друга». Друг заходит по ссылке/коду, оба жмут «Готов», хост запускает.
- Игры для двоих: хост = игрок 1, гость = игрок 2.
- Свой `.nes`: загрузка в IndexedDB браузера (на сервер файл **не уходит**). Для игры вдвоём у обоих
  должен быть один и тот же файл — лобби сверяет SHA-256, гостю предложат выбрать файл с телефона.

## Запуск
```bash
npm install
cp .env.example .env     # впиши BOT_TOKEN и BOT_USERNAME
npm start                # по умолчанию порт 8795
npm test                 # сетевой тест + headless-браузер (нужен Chrome, см. test/test-browser.js)
```
Без `BOT_TOKEN` сервер работает (гости разрешены, initData не проверяется) — удобно для локальной отладки.
С `BOT_TOKEN` проверяется HMAC подписи `initData`; невалидные подключения отклоняются
(кроме случая `ALLOW_GUESTS=1`).

Переменные `.env`: `PORT`, `BOT_TOKEN`, `BOT_USERNAME` (без @), `APP_SHORT_NAME` (если Mini App создан
через `/newapp`, ссылка станет `t.me/<bot>/<short>?startapp=<код>`), `ALLOW_GUESTS`.

## Подключение в Telegram через BotFather
Нужен **новый** бот (токен выдаёт только владелец в @BotFather).
1. `@BotFather` → `/newbot` → получи токен → положи в `.env` как `BOT_TOKEN`, имя бота — в `BOT_USERNAME`.
2. Приложение должно быть доступно по **HTTPS** (Mini App не работает с http). Варианты: свой домен + reverse proxy
   (nginx/caddy) на порт 8795, либо `cloudflared tunnel --url http://localhost:8795` для теста.
   WebSocket (`/ws`) должен проксироваться тоже.
3. Кнопка меню: `/setmenubutton` → выбери бота → URL приложения → название «Играть».
   Либо полноценный Mini App: `/newapp` → выбери бота → URL → short name (впиши в `APP_SHORT_NAME`).
4. Открой бота, нажми кнопку — приложение откроется. «Позвать друга» отправит приглашение со ссылкой `startapp`.

## Как добавить ещё ROM-ы (только легальные!)
1. Положи файл в `roms/`.
2. Добавь запись в `roms/games.json`: `id`, `title`, `file`, `players` (1 или 2), `desc`, `author`, `license`, `source`.
3. Добавь текст лицензии в `LICENSES/` и строку в `LICENSES/CREDITS.md`.
4. Перезапусти сервер (SHA-256 считается автоматически).

Добавляй только то, что можно свободно распространять (homebrew с открытой лицензией, public domain, разрешение автора).
Коммерческие игры Dendy/NES в репозиторий класть нельзя — для них есть загрузка своего `.nes` пользователем.

## Включённые игры
См. `LICENSES/CREDITS.md` — 4 homebrew-игры (MIT, zlib, GPL-3.0, permissive) со ссылками на источники.

## Как устроен сетевой режим
- Сервер (`server.js`, express + ws) только релеит: лобби в памяти процесса, ввод игроков пересылается как есть.
- Lockstep: эмулятор у каждого свой и детерминированный; ввод на кадр `f+4` отправляется заранее,
  кадр `f` не считается, пока не пришёл ввод соперника (при лаге — оверлей «ждём соперника»).
- Каждые 60 кадров игроки обмениваются чек-суммой RAM; при расхождении показывается сообщение о рассинхроне.
- Отключение соперника → хост возвращается в лобби, гость видит сообщение.

## Ограничения
- jsnes эмулирует NTSC (60 Гц). Dendy — PAL-клон (50 Гц), игры, рассчитанные на PAL, могут идти чуть быстрее/иначе.
- Поддерживаются популярные мапперы jsnes (NROM, MMC1, UxROM, CNROM, MMC3, AxROM и др.); проверка при загрузке.
- Лобби хранятся в памяти одного процесса (после рестарта пропадают); TTL лобби — 6 часов.
- Звук стартует после первого касания (требование браузеров).

## Структура
```
server.js            express + ws, конфиг, лобби/релей
lib/telegram.js      проверка initData (HMAC-SHA256)
lib/lobbies.js       логика лобби
public/              фронтенд (index.html, css, js, vendor/jsnes.min.js)
roms/                легальные ROM-ы + games.json
LICENSES/            лицензии и credits
test/                test-net.js (протокол), test-browser.js (headless Chrome)
```
